# UI Geneology — Ubuntu HRMS

Complete hierarchy of UI elements across all dashboards, showing navigation paths and leaf node content.

| Dashboard | Sidebar + Header | Interactive Elements (Drill-down) | Leaf Node Content |
|-----------|------------------|----------------------------------|-------------------|
| **Admin** | **Overview** → Dashboard | - Stats cards (clickable): Total Employees → /admin/employees, Present Today → /admin/attendance, Pending Payroll → /admin/payroll, Avg KPI → /admin/kpis<br>- Quick Actions: Approve Leaves → /admin/leaves, Generate Payroll → /admin/payroll, View Complaints → /admin/complaints, Check Attendance → /admin/attendance, Review KPIs → /admin/kpis, Settings → /admin/settings<br>- Tabs: Overview, Employees, Attendance, Payroll, KPIs, Analytics | - Overview: Stats cards display, Quick Actions grid, System Status (API/DB/Last Sync)<br>- Employees tab: DataTable with employee list (Name, Department, Role, Status badges) → click row → /admin/employees/:id<br>- Attendance tab: Empty state with "View Full Attendance" button<br>- Payroll tab: 3 stat cards (Pending Payroll, Total Employees, Active Cycle) + "Manage Payroll" button<br>- KPIs tab: 2 stat cards (Avg KPI Score, Employees Evaluated) + "Manage KPIs" button<br>- Analytics tab: BarChart (Recent Payroll Payouts), PieChart (Employee Distribution) |
| **Admin** | **Employees** → Employees | - DataTable with employee list → click row → /admin/employees/:id<br>- Tabs: Overview, Employees, Attendance, Payroll, KPIs, Analytics | - Employee list table with Name, Department, Role, Status (Active badge)<br>- Click row → EmployeeDetail page |
| **Admin** | **Employees** → Users | - DataTable with user list → click row → /admin/users/:userId | - User list table with user information<br>- Click row → UserDetail page |
| **Admin** | **Attendance** → Attendance | - Tabs: Overview, Employees, Attendance, Payroll, KPIs, Analytics | - Attendance records table with Date, Check In, Check Out, Status<br>- Click row → /admin/attendance/:attendanceId |
| **Admin** | **Attendance** → Leave and Off-days | - Leave request list with status badges<br>- Approve/Reject buttons | - Leave requests table with Employee, Type, Dates, Status<br>- Approve/Reject actions update status |
| **Admin** | **Attendance** → Statutory Leave Review | - Statutory leave rules table<br>- Edit buttons | - Statutory leave policy table with leave types, entitlements, rules<br>- Edit opens form to update policy |
| **Admin** | **Payroll** → Payroll Management | - Payroll list table with status badges<br>- Generate button → opens period selection form<br>- Export button | - Payroll records table with Employee, Period, Gross, Net, Status<br>- Generate opens modal to select period and calculate<br>- Export downloads CSV/PDF |
| **Admin** | **Payroll** → Disburse Payroll | - Payroll list with "Pending" status<br>- Approve button per row<br>- Batch Approve button | - Pending payroll records table<br>- Approve marks as "Disbursed"<br>- Batch Approve processes all selected |
| **Admin** | **Settings** → Settings | - Settings categories: General, Attendance, Payroll, Leave, KPI, Notifications<br>- Save button | - Settings form with category tabs<br>- Each category has input fields (text, number, select, toggle)<br>- Save updates settings in database |
| **Admin** | **Reports** → Reports | - Report type selector: Attendance, Payroll, Leave, KPI, Employee<br>- Date range picker<br>- Generate button<br>- Export button | - Report type selection form<br>- Generate displays table/chart based on type<br>- Export downloads as PDF/Excel |
| **Admin** | **Assets** → Assets | - Asset list table with status badges<br>- Add Asset button → opens form<br>- Edit/Delete buttons per row | - Asset inventory table with Name, Type, Status, Assigned To<br>- Add opens form to create new asset<br>- Edit opens form to update<br>- Delete removes asset |
| **Admin** | **Contracts** → Contracts | - Contract list table with status badges<br>- Create Contract button → opens form<br>- View button per row | - Contract records table with Employee, Type, Start Date, End Date, Status<br>- Create opens form to add contract<br>- View shows contract details |
| **Admin** | **Contracts** → Review Submissions | - Pending contract submissions list<br>- Approve/Reject buttons | - Contract review table with Contractor, Project, Terms<br>- Approve accepts contract<br>- Reject returns with reason |
| **Admin** | **Contractors** → Contractors | - Contractor list table<br>- Add Contractor button → opens form<br>- View button per row | - Contractor records table with Name, Company, Status<br>- Add opens form to register contractor<br>- View shows contractor profile |
| **Admin** | **Workforce** → Onboarding | - Onboarding checklist table<br>- Start Onboarding button<br>- Progress tracker | - Onboarding tasks table with Task, Status, Due Date<br>- Start initiates onboarding process<br>- Progress shows completion percentage |
| **Admin** | **Workforce** → Daily Labour | - Daily labourer list table<br>- Add Labourer button → opens form<br>- Approve Wages button | - Labourer records table with Name, Skill Set, Daily Rate, Status<br>- Add opens form to register labourer<br>- Approve Wages processes pending payments |
| **Admin** | **Performance** → KPIs | - KPI list table with scores<br>- Set KPI button → opens form<br>- Assess button per row | - KPI records table with Employee, Definition, Target, Achieved, Score<br>- Set opens form to create KPI<br>- Assess opens evaluation form |
| **Admin** | **Performance** → Training & Development | - Training list table<br>- Add Training button → opens form<br>- Assign button per row | - Training records table with Title, Type, Date, Attendees<br>- Add opens form to create training<br>- Assign opens employee selection |
| **Admin** | **Organisation** → Org Chart | - Department hierarchy tree<br>- Expand/collapse nodes<br>- Click department → shows employees | - Visual org chart with departments as nodes<br>- Expand shows sub-departments<br>- Click shows employee list for department |
| **Admin** | **Organisation** → Document Vault | - Document list table with type badges<br>- Upload button → opens file picker<br>- Download button per row | - Employee documents table with Employee, Type (National ID, KRA, NSSF, NHIF, Certificate), Status<br>- Upload stores document<br>- Download retrieves file |
| **Admin** | **Complaints** → Complaints | - Complaint list table with status badges<br>- Resolve button per row<br>- View button per row | - Complaint records table with Employee, Type, Description, Status, Date<br>- Resolve opens resolution form<br>- View shows full complaint details |
| **Admin** | **Hiring** → Recruitment | - Job postings list table<br>- Create Job button → opens form<br>- View Applicants button per row | - Job postings table with Title, Department, Status, Deadline<br>- Create opens job creation form<br>- View Applicants → /recruitment/jobs/:jobId/applicants |
| **Manager** | **Overview** → Dashboard | - Stats cards: Team Size → /admin/employees, Present Today → /manager/attendance, Pending Approvals → /leave/approvals, Team Avg KPI → /kpi/manage<br>- Quick Actions: Review Leaves → /leave/approvals, Manage Attendance → /manager/attendance, Set KPI Goals → /kpi/manage, Disburse Payroll → /payroll/disburse, Leave Overview → /manager/leaves<br>- Tabs: Overview, Team Members, Attendance, Leaves, KPIs<br>- Performance bars: Attendance Rate (85%), KPI Achievement (82%), Leave Utilization (45%) | - Overview: Stats cards, Quick Actions grid, Performance progress bars<br>- Team Members tab: DataTable with team list → click row → /admin/employees/:id<br>- Attendance tab: Empty state with "View Full Attendance" button<br>- Leaves tab: 3 stat cards (Pending Approvals, Approved This Month, On Leave Today) + "Review Pending Leaves" button<br>- KPIs tab: Empty state with "Manage KPIs" button |
| **Manager** | **Attendance** → Attendance | - Attendance records table<br>- Filter by date range<br>- Export button | - Team attendance table with Employee, Date, Check In, Check Out, Status<br>- Filter narrows by date range<br>- Export downloads CSV |
| **Manager** | **Attendance** → Leave and Off-days Overview | - Leave balance summary cards<br>- Leave request list | - Leave balance cards per employee<br>- Leave requests table with status |
| **Manager** | **Attendance** → Leave and Off-days Management | - Pending leave requests list<br>- Approve/Reject buttons | - Leave approval queue table<br>- Approve/Reject actions update status |
| **Manager** | **Attendance** → Statutory Leave Review | - Statutory leave policy table<br>- View-only | - Statutory leave rules display (read-only for managers) |
| **Manager** | **Team** → Team Members | - DataTable with team list → click row → /admin/employees/:id | - Team members table with Name, Department, Type (Permanent/Contract) |
| **Manager** | **Performance** → Manage KPIs | - KPI list table<br>- Set KPI button → opens form<br>- Assess button per row | - KPI records table with Employee, Definition, Target<br>- Set opens KPI creation form<br>- Assess opens evaluation form |

| **Manager** | **Onboarding** → Onboarding | - Onboarding checklist table<br>- Start Onboarding button<br>- Progress tracker | - Onboarding tasks table with Task, Status, Due Date<br>- Start initiates onboarding<br>- Progress shows completion |
