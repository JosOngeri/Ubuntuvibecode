📊 Payroll Computation Formula
Gross Pay = Base Rate
              + (Overtime Hours × Overtime Rate)
              + KPI Bonus (from pending_bonuses)
              + Allowances

Net Pay    = Gross Pay
              − PAYE (Tax)
              − NSSF
              − NHIF
              − Other Deductions

Disbursed via M-PESA B2C → Employee phone number
👥 All Workers — What You Do in This System
Each role has a dedicated dashboard and set of actions. Here is what each person can do.

🛡️ Admin / HR Manager

  • Create and manage all users & employees
  • Post jobs, screen applicants, send offers
  • Initiate onboarding for new hires
  • Configure leave policies and KPI definitions
  • Run payroll and disburse via M-PESA
  • Manage contracts, assets, settings
  • View and export all reports
  • Manage contractor lifecycle and invoices
  • Handle complaints and notifications

👔 Manager / Supervisor

  • View team attendance and approve records
  • Approve or reject leave requests
  • Create and assign KPI targets to team members
  • Record KPI assessment scores
  • Conduct mid-point and final probation reviews
  • Review and approve contractor milestones
  • View team reports and dashboards
  • Manage recruitment for own department

🧑‍💻 Employee

  • Punch in/out for attendance (manual or mobile)
  • Request leave and view leave balance
  • View own KPI goals and scores
  • Download own payslips
  • Submit complaints
  • Browse job board & apply to internal openings
  • Track own applications
  • Update profile information

🏗️ Contractor

  • View assigned projects
  • Submit milestone deliverables via portal
  • Upload and track invoices
  • View own KPI performance rating
  • Update profile and certifications

👷 Daily Labourer

  • View own attendance records
  • View daily payment history
  • Access personal dashboard
  • Update profile

⚙️ Technical Architecture
Full stack breakdown, API surface, data models, and system design decisions.

🖥️ Frontend Stack

  • React 18 + Vite
  • TailwindCSS
  • React Router v6
  • Recharts (data viz)
  • React Toastify
  • Axios API client
  • Context API (Settings, Auth)

🗄️ Backend Stack

  • Node.js + Express.js
  • PostgreSQL (pg pool)
  • JWT Authentication
  • Multer (CV uploads)
  • PDFKit (report generation)
  • Nodemailer (email)
  • M-PESA B2C (payments)

🗃️ Key Database Tables

  • users, employees
  • jobs, job_applications
  • attendance, leave_requests, leave_balances
  • kpi_definitions, employee_kpis, pending_bonuses
  • pay_rates, payslips
  • onboarding, profiles
  • projects, invoices, contractor_performance
  • daily_labourers, daily_attendance
  • notifications, settings, shift_settings

🔐 Security Design

  • JWT tokens (auth middleware)
  • Role-based route guards (admin/manager/employee/contractor)
  • Bcrypt password hashing
  • Offer letter tokens (crypto random)
  • CORS configured per environment
  • Settings audit log for all config changes
  • Must-change-password flag for new users

📡 API Modules

  • /api/auth — login, register, password
  • /api/jobs — CRUD, applications, scoring
  • /api/employees — CRUD, profiles
  • /api/attendance — punch, reports
  • /api/leave — requests, approvals, balances
  • /api/kpi — definitions, assignments, assessment
  • /api/payroll — compute, disburse, payslips
  • /api/onboarding — initiate, checklist, confirm
  • /api/reports — all report types
  • /api/contractors — lifecycle, invoices, performance
  • /api/daily-labourers — register, attendance, pay
  • /api/notifications — CRUD, mark read
  • /api/settings — system configuration

🚀 Deployment Notes

  • Frontend: Netlify / Vercel (static)
  • Backend: Railway / Render / VPS
  • DB: Neon / Supabase / PostgreSQL VPS
  • Env vars: DATABASE_URL, JWT_SECRET, MPESA keys, Email SMTP
  • init-database.sql → schema setup
  • seed-data.sql → dummy data
🔧 Suggested Improvements — Prioritised
🔴 High Priority

Mobile App (Android)

Implementation guide exists. Field workers and daily labourers need mobile punch-in. Geo-fencing works best on mobile. Accelerates attendance accuracy significantly.

🔴 High Priority

Biometric / RFID Integration

Hardware-level attendance verification eliminates buddy-punching and proxy attendance entirely. Can integrate with existing fingerprint scanners via API bridge.

🔴 High Priority

Training & Development Module

Track employee courses, certifications, skill gaps, and training budgets. Link training completion to KPI scores. Currently the weakest gap vs global standards.

🟡 Medium Priority

Document Management System (DMS)

Store, version, and retrieve employee documents (ID scans, contracts, certificates) as files directly in the system with expiry alerts for certificates.

🟡 Medium Priority

360° Feedback / Peer Reviews

Allow employees to give feedback on peers and managers, not just manager-to-employee KPI. More holistic performance view aligned with modern HR practices.

🟡 Medium Priority

Org Chart & Hierarchy Visualization

Interactive org chart showing departments, reporting lines, headcount per department. Useful for owners to visualise the business structure at a glance.

🟢 Low Priority

Advanced Analytics Dashboard

Predictive analytics: turnover risk, attendance trend forecasting, payroll projection. Currently basic charts — could add trend lines, forecasts, and drill-downs.

🟢 Low Priority

Succession Planning

Flag high-performing employees for promotion pipelines. Track readiness scores and career progression paths. Helps retain talent with visible growth paths.

🟢 Low Priority

Multi-tenancy / Multi-branch

Support multiple office locations or business branches under one system. Currently single-branch. Useful as the business grows or expands to new locations.
